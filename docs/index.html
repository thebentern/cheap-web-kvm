cheap-web-kvm

A USB KVM built from one ESP32-S3 dev board and an off-the-shelf HDMI capture stick. Control a headless machine from a browser — keyboard, mouse and video — with no drivers and nothing to install.

How it fits together

  laptop ──USB-C──> [UART port: CH343/CP2102N] ─UART0─┐
                                                      ├── ESP32-S3
  target <──USB-C── [USB port: native OTG, GPIO19/20] ┘

  target ──HDMI──> MS2130 ──USB-A──> laptop   (independent, no firmware involvement)

The browser talks to the ESP32-S3 over Web Serial using the CH9329 protocol. The firmware turns those frames into USB HID reports and presents a boot-protocol keyboard plus an absolute mouse to the target. Video is a separate path entirely — the capture stick is a standalone UVC device and the firmware has nothing to do with it.

Requirements

  • A Chromium-based browser — Web Serial is not in Firefox or Safari
  • HTTPS or localhost — Web Serial needs a secure context
  • ESP32-S3 running this firmware, at 115200 baud
  • An MS2130 or MS2109 HDMI capture dongle

Unlike a stock CH9329, which ships at 9600 baud and has to be reconfigured before first use, this firmware comes up at 115200 directly. There is no baud-rate setup step.
